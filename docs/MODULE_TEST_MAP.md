The destination runtime path and test status are intentionally completed from the new implementation as it lands. A row is not complete merely because a source file exists or a build succeeds. Every retained module needs a reachable user-facing or owner-facing entry point, real enabled behavior, and a test of that enabled behavior. A generic feature registry, CRUD placeholder, copied domain core that is never dispatched, or default-off response alone does not satisfy retention.

## Test ownership and evidence ledger

QA adds target-native tests under `tests/`. Test the actual Worker HTTP entry point and isolated D1 state; use injected verification/provider dependencies only at explicit seams. Do not duplicate legacy helper-level assertions under new filenames and call them extraction coverage.

For each row, the destination entry must identify (a) the reachable route/page or operator action, (b) its real handler/module, (c) required configuration and authorization, (d) the enabled success-path test, and (e) the disabled/unconfigured and denial-path tests. A handler that always returns a generic inventory record is not a retained implementation. If a capability cannot be implemented completely, report the gap to Lead and Architect for a scope decision instead of relabeling a placeholder as optional support.

For each row, append the concrete implementation path(s), test path(s), command, result, date, and known limits when verified. Use these states:

- `planned`: acceptance is defined; implementation/test not yet evidenced.
- `local-pass`: named HTTP/D1 test command passed against this local checkout.
- `browser-unverified`: no authorized supported browser session has exercised the behavior.
- `provider-unverified`: no authorized live provider readback has confirmed behavior.
- `native-unverified`: no Cloudflare deployment/version readback has confirmed behavior.

Never promote a source reference or test fixture to a pass state. Provider and AI fixture calls must be observable and assert zero outbound calls for disabled/unconfigured features.
